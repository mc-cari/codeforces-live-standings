Codeforces API call paths

What the live and replay screens ask the app backend for, what the backend actually sends upstream to Codeforces, and where handle filtering really happens.

The expensive path is intentionally visible: contest.status does not receive a Codeforces-side handle filter. The app backend fetches every submission for the contest and filters the response by selected handles before returning it to the browser. Browser call timing is shown below; successful backend responses are cached and identical in-flight requests are shared.
